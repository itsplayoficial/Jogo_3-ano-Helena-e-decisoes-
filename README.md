# A trilha das decisões da Helena

Jogo de verdadeiro ou falso para o 3º ano, inspirado nas páginas de referência da atividade da Helena. São nove desafios em ordem aleatória por partida: três de matemática (adição, multiplicação e divisão exata), três de formas geométricas e três de meio ambiente e reciclagem. Helena aparece pequena e de costas diante de uma bifurcação ilustrada, pula de alegria no acerto e fica triste no erro. Há feedback sonoro e explicações; a pergunta seguinte aparece automaticamente após 4,8 segundos. Ao fim, aparecem o resultado e a opção de reiniciar. Funciona sem serviços externos ou instalação.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub e envie os arquivos de `jogo-helena` para a raiz (incluindo a pasta `assets`).
2. No repositório, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`, e salve.
3. A página ficará no endereço mostrado pela seção Pages. Pode levar alguns minutos para aparecer.

Para testar localmente, abra `index.html` no navegador. O som começa após o primeiro toque/clique, conforme as regras do navegador.
